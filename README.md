# CastMap - 案件（スケジュール）管理アプリ

> タレントマネージャー向けスケジュール管理サービス「CastMap」の一部として制作した、案件登録・一覧アプリ。
> 今週の課題（DBを扱うWebアプリ）として、スケジュール管理アプリのパーツをPHP＋MySQLで実装したもの。

- 公開URL: https://prema.sakura.ne.jp/booking_app/select.php
- ※2026.10 php脆弱性のため公開停止
- 使用技術: PHP / MySQL(MariaDB) / HTML / CSS / JavaScript

---

## （1）制作アプリのタイトル

**CastMap（案件管理パーツ）**

## （2）制作アプリの説明

タレントの「案件（スケジュール）」を登録し、一覧で確認できるWebアプリ。
案件名・タレント名・場所・日時・ステータス（打診中／仮／確定／完了）をフォームから登録すると、
データベースに保存され、一覧画面に表示される。

これは開発中のスケジュール管理ツール「CastMap（仮称）」の心臓部にあたる部分。
CastMapは「担当タレントが増えると“全員の予定が頭に入らない”」という課題を、
案件（タレント×場所×日時）を一元管理し、認知負荷を軽減し視覚的にスケジュール管理に対する負荷を改善するのが狙い。
今回はその土台となる「案件データの登録・保存・表示（CRUDのC・R）」を形にした。

## 技術仕様

### ファイル構成（課題の input / create / select に対応）

| ファイル | 役割 |
|---|---|

## （3）工夫した点・こだわった点

- **セキュリティ対策**
  - SQL実行はすべて**プリペアドステートメント**で行い、SQLインジェクションを防止
  - 画面表示は `htmlspecialchars()` を通し、XSS対策
  - ステータスは**ホワイトリスト**で不正な値の混入を防止
- **PRGパターン**：登録後はリダイレクトし、ブラウザ再読み込みによる二重登録を防止
- **環境の自動切り替え**：`$_SERVER['SERVER_NAME']` を見て、ローカル(XAMPP)と本番(さくら)のDB設定を自動で切り替え。デプロイのたびに書き換えなくて済むようにした
- **秘密情報の分離**：DBパスワード等を含む `config.php` は `.gitignore` で除外し、テンプレート `config.sample.php` のみ公開
- **JavaScriptの追加**
  - 開始日時を選ぶと終了日時を自動で+2時間に補完
  - 一覧をキーワードで絞り込み（ページ再読み込みなし）
- **UI**：ステータスを色分けバッジで表示し、状態が一目で分かるようにした
- **データベースの作成** : web上でポトポチとデータベースを登録するものだと思い始めはそのように着手したが、コードで一気にデータベースを作成できることがわかり、その方法を取り入れてみることにした。ローカルでは db.sql で CREATE DATABASE ごと作成。本番のさくらはコントロールパネルでDB作成。

## （4）難しかった点・次回トライしたいこと

### 難しかった点
- **XAMPPのMySQLが起動しないトラブル**：ログに `InnoDB: Unable to lock ibdata1 error: 35` が出て起動できず苦戦。原因は、以前起動したmysqldプロセスが裏で生き残ってデータファイルをロックしていたこと（Macのホスト名変更でpid管理がズレていた）。ログの読み方とプロセスの止め方を学べた。
- **PHPがどうやってDBに繋がっているのかの理解**：`new PDO(...)` で接続し、SQLを送って結果を受け取る、という一連の仕組みが最初は曖昧だった。SELECT/INSERTの文法やプレースホルダの意味を1つずつ確認して腑に落とした。
- **さくらへのデプロイ**：DB名の接頭辞（アカウント名＋`_`）や「ユーザー名＝データベース名」などさくら固有のルール、3種類のパスワードの使い分けに戸惑った。

### 次回トライしたいこと
- **UPDATE / DELETE を実装**して、完全なCRUDにする（案件の編集・削除）
- タレントを**別テーブルに分けてリレーション**（正規化）
- この案件データを、CastMap本体の**地図ビュー・タイムライン**に接続する
- 入力バリデーションの強化、ログイン機能によるユーザーごとのデータ管理

## ローカルでの動かし方

1. XAMPPでApache・MySQLを起動
2. phpMyAdminで `db.sql` を実行し、DB `castmap` とテーブルを作成
3. `config.sample.php` を `config.php` にコピー（ローカル設定はそのままでOK）
4. `booking_app` を `htdocs` に置き、`http://localhost/booking_app/select.php` を開く
